## Brand & Style

This design system sets the visual benchmark for high-performance B2B subscription operations. Tailored for enterprise administrators and support personnel managing IPTV services for Arab-American communities, the aesthetic balances high-density utility with bilingual clarity.

### Personality & Emotional Response
- **Trustworthy & Resolute:** Instills administrative confidence through deterministic layout behavior, precise data tabular displays, and high-visibility status states.
- **Modern & Culturally Native:** Treats Arabic and English typography as equals, providing identical visual weight, optical alignment, and natural flow across bidirectional layouts.
- **Focused & Non-Distractive:** Subdued chrome and slate surfaces recede, letting operational metrics, device streams, MAC address profiles, and subscriber statuses lead.

### Design Movement: Modern Precision SaaS
A synthesis of clean corporate architecture and modern data density. The system relies on:
- High contrast, crisp 1px borders using muted slate.
- Micro-diffused ambient elevations for layer differentiation without visual noise.
- Generous text leading tailored specifically to Arabic letterforms to prevent ascender/descender collisions.
- Dedicated semantic signifiers for subscription lifecycle phases (Active, Pending, Expired).

## Colors

The system uses a focused palette centered around an authoritative Sapphire Blue, backed by functional slates and deterministic lifecycle signals. Every combination meets or exceeds WCAG AA contrast ratios (4.5:1 for body copy, 3:1 for graphical interfaces).

### Core Role Assignments
- **Primary (`#1d4ed8` - Sapphire Blue):** Primary actions, active navigation states, selected table rows, high-priority interactive cues, and system focus rings (via 20% alpha tint).
- **Secondary (`#10b981` - Emerald):** Lifecycle health indicator: Active subscription, validated connection, stream operational, successful payment.
- **Tertiary (`#f59e0b` - Amber):** Warning indicator: Expiring soon (≤7 days), payment pending, connection throttling, hardware bandwidth warning.
- **Destructive / Alert (`#ef4444` - Rose):** Lifecycle termination: Inactive subscription, MAC address blacklisted, stream failure, auth token revoked.
- **Neutral Core (`#0f172a` - Slate 900):** Primary high-contrast text and critical headings.

### Surface Architecture
- **App Background:** `#f8fafc` (Slate 50) - Base canvas layer.
- **Card & Panel Surface:** `#ffffff` - Elevated operational plane.
- **Muted Surface:** `#f1f5f9` (Slate 100) - Table headers, disabled form controls, code/MAC address chips.
- **Structural Border:** `#e2e8f0` (Slate 200) - 1px boundary lines dividing panes, tables, and card perimeters.
- **Subdued Text:** `#64748b` (Slate 500) - Meta attributes, column sorting indicators, and timestamp tags.

## Typography

The type system uses `IBM Plex Sans` (paired with `IBM Plex Sans Arabic` in bilingual execution) and `JetBrains Mono` for hardware signatures (MAC addresses, Xtream UI tokens, IP addresses). 

### Arabic & RTL Typesetting Principles
- **Extended Vertical Line Height:** Arabic characters feature taller ascenders and deep descenders compared to Latin equivalents. Standard 1.2 or 1.4 line heights cause clipping or cluttered visual rhythm; all body and label tokens feature generous vertical spacing (minimum 1.6x to 1.7x proportional leading) to preserve diacritics and ligatures.
- **Weight Calibration:** Arabic letterforms in IBM Plex Sans appear visually heavier than Latin forms at identical weights. In dense tables, favor Medium (`500`) over SemiBold (`600`) for headers to prevent typographic congestion.
- **Monospace Pairing:** Serial keys, MAC addresses, port mappings, and m3u URLs must remain strictly LTR (`dir="ltr"`) even within an RTL context, typeset in `JetBrains Mono` for rapid identification and zero character ambiguity (distinguishing `0` vs `O`, `1` vs `l`).

## Layout & Spacing

The interface operates on a disciplined 8px base grid unit (`0.5rem`). Every layout spacing, padding, gap, and margin must resolve to a multiple of 8px (8px, 16px, 24px, 32px, 48px).

### Layout Grid Model
- **Desktop (≥ 1280px):** 12-column layout with 24px (`1.5rem`) gutters and a fixed 280px navigation rail. Outer margins are locked to 32px (`2rem`). The canvas expands fluids up to 1600px max container width.
- **Tablet (768px - 1279px):** 8-column layout with 16px (`1rem`) gutters. The navigation rail collapses into an icon-only or off-canvas drawer. Outer canvas margin is 24px (`1.5rem`).
- **Mobile (< 768px):** 4-column layout with 16px gutters and 16px margins. Tabular content adapts into stacked card structures.

### Bidirectional Adaptation (LTR to RTL)
- Use logical CSS properties exclusively (`margin-inline-start`, `padding-inline-end`, `inset-inline-start`).
- Data grids reverse column order naturally: subscriber profile begins on the far right, while trailing actions (edit, renew, kill connection) reside on the far left.
- Stat indicators, trend vectors, and navigation icons flip across the vertical axis, while numeric metrics, stream bitrates, and IP addresses remain LTR.

## Elevation & Depth

This system avoids heavy drop shadows to preserve operational clarity in dense administration workflows. Depth is established through structural surface tiers and soft ambient shadows.

### Surface Tiers
- **Base (Level 0):** Canvas `#f8fafc`. Houses non-interactive background areas.
- **Layer 1 (Cards & Data Tables):** Surface `#ffffff`, perimeter 1px border `#e2e8f0`, shadow `0 1px 3px 0 rgba(15, 23, 42, 0.05)`.
- **Layer 2 (Dropdowns, Flyouts & Tooltips):** Surface `#ffffff`, perimeter 1px border `#cbd5e1`, shadow `0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.06)`.
- **Layer 3 (Modals & Slide-over Drawer Sheets):** Surface `#ffffff`, shadow `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`. Accompanied by a 40% opacity Slate-900 backdrop scrim (`rgba(15, 23, 42, 0.4)`).

### Interactive Elevation
Interactive table rows and actionable cards do not lift in 3D space on hover. Instead, they shift background color to `#f8fafc` or `#f1f5f9` with an instantaneous 100ms ease transition. Focus states leverage a 2px offset ring in Sapphire Blue `#1d4ed8`.

## Shapes

The design system standardizes on a structural 12px radius (`0.75rem`) for core containers, bridging precision with modern accessibility.

### Geometry Specifications
- **Cards, Panels, and Dialogs:** 12px (`0.75rem`).
- **Inputs, Buttons, and Select Menus:** 8px (`0.5rem`) to maintain compact density in form controls.
- **Badges, Status Pills, and Data Chips:** Full pill (`9999px`) for instant differentiation from square and tabular inputs.
- **Interactive Checkboxes:** 4px (`0.25rem`) with 1.5px solid borders.
- **Outer Modals & Alert Banners:** 12px (`0.75rem`).

## Components

### Buttons
- **Primary:** Filled Sapphire Blue (`#1d4ed8`), text `#ffffff`. Hover: `#1e40af`. Active: `#1e3a8a`. Focus: 2px offset outline in `#1d4ed8`. Padding: 8px 16px for desktop, height locked to 40px.
- **Secondary / Outline:** Background `#ffffff`, border 1px solid `#e2e8f0`, text `#0f172a`. Hover: Background `#f8fafc`, border `#cbd5e1`.
- **Destructive:** Background `#fef2f2`, border 1px solid `#fecaca`, text `#dc2626`. Hover: Background `#fee2e2`. Used for subscription termination or device disconnects.
- **Icon Buttons:** Fixed 40x40px or 32x32px squares, border radius 8px, content centered. Always provide bidirectional icon alignment (`transform: scaleX(-1)` for forward/back directional chevrons in RTL).

### Input Fields & Selects
- **Base Architecture:** Height 40px, padding 8px 12px, border 1px solid `#cbd5e1`, background `#ffffff`, radius 8px. Text size 14px, line height 24px.
- **Focus State:** Border `#1d4ed8`, outline 2px solid rgba(29, 78, 216, 0.15), outline-offset 0px.
- **Bilingual Layout:** Helper labels and error validation messages sit directly above and below the field aligned with the active text direction. Leading/trailing icon positions mirror in RTL: search icons anchor to the right in Arabic contexts.

### Status Chips & Badges
- **Pill Shape:** Height 24px, padding 2px 10px, typography `label-sm` (`12px`, weight 500).
- **Active / Operational:** Background `#ecfdf5`, text `#065f46`, border 1px solid `#a7f3d0`. Contains a 6px solid `#10b981` dot aligned to the inline-start.
- **Pending / Expiring:** Background `#fffbeb`, text `#92400e`, border 1px solid `#fde68a`.
- **Expired / Terminated:** Background `#fef2f2`, text `#991b1b`, border 1px solid `#fecaca`.

### Data Tables (Subscription & Device Records)
- **Header:** Height 40px, background `#f8fafc`, bottom border 1px solid `#e2e8f0`. Text `label-sm`, color `#64748b`, uppercase/medium tracking.
- **Row:** Height 52px (standard) or 64px (rich data with customer meta), bottom border 1px solid `#f1f5f9`.
- **Selection State:** Row background transitions to `#eff6ff` with a 2px solid Sapphire Blue inline-start indicator strip.
- **Hardware Identifiers:** MAC and M3U credential tokens must render with `code-sm` typography inside a `#f1f5f9` badge with quick 1-click clipboard copy triggers.

### Cards
- Standard dashboard card wraps within 12px radius, `#ffffff` surface, 1px `#e2e8f0` structural perimeter, and 24px padding (`space-md`). Header actions (refresh, filters, date range) align to the inline-end opposite the card title.
